KCAL LITE — тестовая offline-first WebDAV-синхронизация

1. Сохраните резервную копию старого index.html и экспортируйте JSON из прежней версии приложения.
2. Загрузите index.html, sw.js и manifest.webmanifest в ту же папку GitHub Pages и дождитесь публикации.
3. На iPhone включите Tailscale и проверьте в Safari, что https://pica.tailda1815.ts.net:6065/ доступен (достаточно ответа 401, не вводя пароль).
4. Откройте опубликованную страницу https://newmrdenis.github.io/<имя-репозитория>/ (либо корень сайта, если репозиторий user.github.io).
5. Нажмите '☁️ Не подключено', укажите WebDAV URL, имя пользователя и пароль. Пароль хранится только до завершения сеанса.
6. Если у WebDAV глобальный каталог /home/denis/data/webdav, используйте https://pica.tailda1815.ts.net:6065/kcal-lite/state.json.
   Если у отдельного kcal-пользователя directory указывает сразу на .../kcal-lite, используйте https://pica.tailda1815.ts.net:6065/state.json.
7. Добавьте тестовую запись, нажмите облачную кнопку для проверки статуса; проверьте появление state.json на Pi.
8. Создайте ещё одну запись без сети, подключитесь к Tailscale и синхронизируйте. Для теста двух устройств используйте отдельные записи и удаление.
9. После успешного теста добавьте приложение на экран «Домой» из Safari. Учтите: у установленного PWA и обычного Safari могут быть раздельные данные.

Важно: для синхронизации нужны WebDAV-методы GET, PUT, LOCK, UNLOCK; заголовки Authorization, Content-Type, Depth, Timeout, If, Lock-Token; в exposed_headers — Lock-Token. Ответ OPTIONS 204 ещё не доказывает поддержку Local Network Access в самом браузере. Если Chrome блокирует запрос, проверьте разрешение локальной сети и заголовок Access-Control-Allow-Private-Network; на iOS — Tailscale и браузерные разрешения.

Особенности прототипа: конфликт изменения одной и той же записи решается последним синхронизированным изменением; синхронизация происходит пока приложение открыто, не в фоне после закрытия; автоматический бэкап истории state.json на Pi нужно настраивать отдельно. Не храните пароль WebDAV в исходном HTML.
