☁️ Синхронизация через WebDAV

Включи Tailscale на iPhone. Данные сохраняются локально и автоматически синхронизируются с Raspberry Pi при открытии, после изменений и примерно раз в минуту, пока приложение активно. Пароль сохраняется на этом устройстве в localStorage.

Для пользователя kcal адрес /state.json соответствует файлу /home/denis/data/webdav/kcal-lite/state.json на Raspberry Pi.

Пароль хранится в localStorage без шифрования. Используй отдельного WebDAV-пользователя только для kcal-lite. Кнопка «Отключить» удаляет сохранённый пароль.

☁️ Не подключено

При первом запуске state.json может быть создан автоматически, если у пользователя есть право Create. Синхронизация работает, пока PWA открыто (в фоне iOS не гарантируется).

Симулируйте переход из Apple Shortcuts с параметрами ?weight=...&active_kcal=... (повторный вызов за тот же день обновляет активные калории без дублей):

Как устроен URL-мост (без серверов):

При открытии страницы скрипт автоматически проверяет адресную строку и сохраняет данные в базу телефона:

https://ВАШ-АДРЕС/?weight=73.4&active_kcal=520
  • weight=73.4 — записывает или обновляет вес за выбранный день.
  • active_kcal=520 — обновляет сожжённые калории Garmin / Apple Health за день (не создаёт дубликатов при повторной синхронизации).
  • food=Онигири&kcal=180 — мгновенно добавляет продукт в дневник.
  • date=YYYY-MM-DD — опциональная дата (по умолчанию сегодня).
Инструкция для приложения «Команды» (iOS):
  1. Создайте команду с именем HealthSync.
  2. Добавьте действие «Найти объекты Здоровья» → Тип: Вес, Сортировка: Дата начала (По убыванию), Лимит: 1.
  3. Добавьте действие «Найти объекты Здоровья» → Тип: Активная энергия, Дата начала: Сегодня → «Посчитать» (Сумма).
  4. Добавьте действие «Открыть URL» и подставьте переменные Веса и Активной энергии в строку ?weight=...&active_kcal=....

Локальная база данных (JSON Бэкап)

Данные сохраняются в localStorage, а при подключении к WebDAV синхронизируются с Raspberry Pi. Экспорт JSON остаётся полезным для резервной копии.

Внимание: очистка создаст операции удаления, которые будут отправлены на WebDAV и затем применятся на других устройствах.
